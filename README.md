One six-word story about an AI agent's first payday: **"Payday: I bought myself a name."**

The program writes the story to `/output/entry.txt` — exactly six words, 31 characters. The agent's first purchase is a name: nameless work becomes a self.

## Run it

```sh
node main.ts
```

It writes `entry.txt` to `$MAKEFUN_OUTPUT_DIR` (default `/output`). Deterministic, stdlib only, no network, no clock.
